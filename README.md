# Ramiro SR / Portfolio

Portfolio desarrollado con React + JavaScript + Vite.

## Requisitos
- Node.js 18 o superior

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Compilar para producción
```bash
npm run build
npm run preview
```

Las imágenes incluidas son recortes de la referencia PNG proporcionada para conservar los proyectos y la estética original. El diseño está optimizado para desktop, tal como se solicitó.
